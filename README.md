# 寻迹万物销售测算台

本工具把两份 Excel 的核心口径转成销售前端：

- 成本测算：按产品成本组件计算总成本、最低价带、成本占比。
- 场景评级：按景区等级、客流、门票、文化关联、动线、铺位、陈列、政策、授权输出 S/A/B/C。
- 定价测算：综合成本底线和场景溢价给出建议零售价、我方回款、毛利、可分配渠道毛利。
- 采购/寄售：按单款采购阶梯匹配采购价，并用地区寄售结算价上限校验。
- 提成估算：按合作模式、动销、保证金、账期、数据质量估算单片提成、月提成和收入。
- 产品库：支持新增、编辑、复制、删除、导出和导入产品。

## 规则调整

在“规则参数”页可调整：

- 成本价带、场景价带、管理保留比例、底薪
- S/A/B/C 分数线、扣点、基础计售比、最低计售比、铺货上限、拓新奖金
- 场景评分项分值
- 单款采购阶梯折扣和启用状态
- 合作模式提成率、动销系数、账期系数、数据质量系数

规则会保存在当前浏览器本地，可导出 JSON，也可导入同结构 JSON 恢复。

## 产品库

在“产品库”页可维护产品基础信息和成本组件：

- 产品编码、名称、结构、规格、本体类型、产品大类、产品类型、载体、包装、备注
- 主材、UV、手绘、工艺、载体、包装、定制/授权、损耗、物流等成本

产品库同样保存在当前浏览器本地；“恢复默认产品”会回到本次从 Excel 整理出的初始产品库。
