# 寻迹万物销售测算台

本工具把两份 Excel 的核心口径转成销售前端：

- 成本测算：按产品成本组件计算总成本、最低价带、成本占比。
- 场景评级：按 T0「瓦文化与客群匹配」、T1「收费金额/年客流/店位/店型/空间/商务条件/对方态度」、T2「官方合作/授权联名/官方资源」输出 S/A/B/C/D；T0/T1/T2 默认按 50/45/5 折算到 100 分。
- 景区库：内置首批高适配景区样本，支持搜索、筛选、套用到评级表、导出和导入 JSON。
- 定价测算：综合成本底线和场景溢价给出建议零售价、我方回款、毛利、可分配渠道毛利。
- 采购/寄售：按单款采购阶梯匹配采购价，并用地区寄售结算价上限校验。
- 提成估算：按合作模式、动销、保证金、账期、数据质量估算单片提成、月提成和收入，并模拟谈成更优扣点后的提成变化。
- 产品库：支持新增、编辑、复制、删除、导出和导入产品。

## 访问方式

正式发布后可通过 GitHub Pages 访问。页面是纯静态站点，规则参数、UI 配置、产品库和测算记录默认保存在访问者当前浏览器本地。

本地预览可在项目目录启动临时服务：


```bash
python3 -m http.server 8787
```

然后访问：

`http://127.0.0.1:8787`

## 规则调整

在“规则参数”页可调整：

- 成本价带、场景价带、管理保留比例、底薪
- S/A/B/C/D 分数线、扣点、基础计售比、最低计售比、铺货上限、拓新奖金
- T0/T1/T2 大类权重和组内评分项分值。每个小模块统一 10 分制，小项分值只决定组内排序，系统会按大类权重自动折算为 100 分。
- 单款采购阶梯折扣和启用状态
- 合作模式提成率、动销系数、账期系数、数据质量系数

规则会保存在当前浏览器本地，可导出 JSON，也可导入同结构 JSON 恢复。

经营口径说明见：[规则参数经营策略](./docs/rule-parameter-operating-strategy.md)。

规则参数和 UI 配置修改时会先备份上一版，备份同样保存在当前浏览器本地。不同域名、不同浏览器、不同设备之间不会自动共享本地保存的数据。

## 产品库

在“产品库”页可维护产品基础信息和成本组件：

- 产品编码、名称、结构、规格、本体类型、产品大类、产品类型、载体、包装、备注
- 主材、UV、手绘、工艺、载体、包装、定制/授权、损耗、物流等成本

产品库同样保存在当前浏览器本地；“恢复默认产品”会回到本次从 Excel 整理出的初始产品库。

## 景区库

“景区库”页用于沉淀可公开调研到的基础字段。首批样本会标注客流数据口径，部分是年度景区口径，部分是公开参考口径或待复核线索；销售套用后仍可手动修正店位、商务条件和官方资源。

后续补库建议优先补这些字段：景区名称、城市、景区类型、年客流和数据口径、收费金额、合作店位、店型、店内空间、商务条件、对方态度、是否官方合作、是否授权联名、营销/装补/人力/联票资源。

## 数据说明

本仓库只发布可公开访问的静态页面、前端脚本、轻量化 SKU 展示数据、压缩后的产品图和景区基础库说明。原始 Excel、同步脚本和本地生成中间数据不随 GitHub Pages 发布。
